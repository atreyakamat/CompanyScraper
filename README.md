# Lead Management Monorepo

This repository contains:
- **apps/lead-management-platform**: The main local-first lead management application powered by Ollama.
- **apps/documentation**: The documentation site for the platform.

## Getting Started

### Prerequisites
- Node.js
- Ollama (running locally)

### Commands
- `npm run dev:app`: Start the lead management platform.
- `npm run dev:docs`: Start the documentation site.
- `npm run build:app`: Build the platform for production.
- `npm run build:docs`: Build the documentation site.
